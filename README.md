💊 Daruyab

Daruyab is an Android application for searching medicines and checking their availability in pharmacies.

 ✨ Features

- 🔍 Search medicines by name
- 🏥 View pharmacies that have the medicine in stock
- 📱 Clean and modern Material Design UI
- 🇮🇷 Persian language support
- ⚡ Fast and lightweight

 🛠 Built With

- Kotlin
- RecyclerView
- ViewBinding
- Material Design 3
- Navigation
